# Sepsis Prediction with Machine Learning (Educational Demo)

A beginner-friendly machine-learning project that trains a Random Forest classifier on a **synthetic dataset** and evaluates it using a held-out test set.

> **Safety note:** This is an educational software demo. The data is artificially generated, the labels are synthetic, and the model is not clinically validated. It must not be used to diagnose, screen, or guide treatment for any person.

## Features

- Reproducible synthetic dataset generation
- Data validation and median imputation
- Random Forest classification with class weighting
- Train/test split with stratification
- Accuracy, precision, recall, F1-score, ROC-AUC, and confusion matrix
- Command-line demo prediction
- Automated tests

## Tech stack

Python, NumPy, Pandas, scikit-learn, joblib, unittest.

## Setup

Use Python 3.10 or 3.11 if available.

### Windows (PowerShell)

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If Python 3.10 is not installed, use `py -m venv .venv` to create the environment with your installed Python version.

### macOS/Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Run the project

Run these commands from the project root:

```bash
python generate_data.py
python train.py
```

A synthetic CSV is created in `data/`, and the trained model plus evaluation metrics are saved in `models/`. These generated files are ignored by Git because they can be recreated with the commands above.

### Try a demo prediction

```bash
python predict.py --hr 90 --temp 37.0 --resp 18 --lactate 1.2 --wbc 9.0
```

The model score is only an output from a synthetic-data demo. It is not a real-world probability of sepsis.

## Run tests

```bash
python -m unittest -v test_model.py
```

The tests generate the dataset, train the model, and verify the dataset structure and a sample prediction.

## Dataset

The dataset is generated by `generate_data.py` using random values and an artificial scoring rule. It contains these columns:

| Column | Description |
|---|---|
| `HR` | Synthetic heart rate value |
| `Temp` | Synthetic temperature value |
| `Resp` | Synthetic respiratory rate value |
| `Lactate` | Synthetic lactate value |
| `WBC` | Synthetic white blood cell count |
| `SepsisLabel` | Artificial binary label (0 or 1) |

This is **not real patient data**. The generated labels are based on a deliberately simplified synthetic rule and random noise; good evaluation metrics do not demonstrate clinical validity.
