# Sepsis Prediction with Machine Learning

An educational machine learning project that demonstrates binary classification using a Random Forest model and a synthetic dataset.

> **Disclaimer:** This project uses artificially generated data and labels. It is not clinically validated and must not be used for medical diagnosis, screening, or treatment decisions.

## Features

- Synthetic dataset generation
- Data validation and missing-value imputation
- Random Forest classification
- Stratified train-test split
- Model evaluation using accuracy, precision, recall, F1-score, ROC-AUC, and confusion matrix
- Command-line prediction
- Automated tests

## Tech Stack

- Python
- NumPy and Pandas
- Scikit-learn
- Joblib
- Unittest

## Setup

Python 3.10 or later is recommended.

### Windows (PowerShell)

Create and activate a virtual environment:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### macOS/Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Generate Data and Train the Model

Run these commands from the project root:

```bash
python generate_data.py
python train.py
```

The synthetic dataset is saved under `data/`, and the trained model and evaluation metrics are saved under `models/`.

## Run a Demo Prediction

```bash
python predict.py --hr 90 --temp 37.0 --resp 18 --lactate 1.2 --wbc 9.0
```

The output is a demonstration model prediction, not a real-world medical risk estimate.

## Run Tests

```bash
python -m unittest -v test_model.py
```

The tests check the generated dataset and whether the saved model can make a prediction.

## Dataset

The dataset is generated by `generate_data.py`. It contains synthetic values for these features:

| Column | Description |
|---|---|
| `HR` | Synthetic heart rate |
| `Temp` | Synthetic temperature |
| `Resp` | Synthetic respiratory rate |
| `Lactate` | Synthetic lactate |
| `WBC` | Synthetic white blood cell count |
| `SepsisLabel` | Artificial binary label (0 or 1) |

These labels are generated using a simplified artificial scoring rule and random noise. Model evaluation results on this dataset do not establish clinical validity.

## Current Evaluation

On the current held-out synthetic test set, the model produced:

- Accuracy: 60.0%
- Precision: 52.5%
- Recall: 52.5%
- F1-score: 52.5%
- ROC-AUC: 0.595

These metrics are specific to this synthetic dataset and should not be interpreted as real-world clinical performance.
